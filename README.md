# ☄️ 태양계 천체 역학적 분류 · Data Science Astronomy Lab

실제 태양계 천체의 **궤도요소와 카탈로그 데이터**를 이용해 행성·왜소행성·소행성·혜성의 역학적 특성과 분류 기준을 탐구하는 교육 콘텐츠입니다.

> **가장 쉬운 실행 방법:** Google Colab  
> **설치:** 필요 없음  
> **핵심 흐름:** 데이터 수집 → 탐색 → 처리 → 분류 기준 분석 → 2D/3D 궤도 시각화 → 결과 해석

1. 위 **Colab에서 바로 실행하기**를 누릅니다.
2. Google 계정으로 로그인합니다.

### 처음에는 이렇게 해보세요

- 분류 기준 산점도: `a(장반경)` × `e(이심률)`
- 데이터 세트: `df`
- 개별 천체 식별번호: `1` (Ceres)
- 궤도선 점 개수: `201`

> 계산이 느리면 궤도선 점 개수(`nps`)를 **101~201**로 낮추면 훨씬 가볍게 실행됩니다.

## 🔭 무엇을 탐구하나요?

- 장반경(semi-major axis)
- 이심률(eccentricity)
- 궤도경사각(inclination)
- 근일점·원일점 거리
- 지구와의 최소 궤도 교차거리(MOID)
- 목성 티세랑(Jupiter Tisserand)
- 행성·왜소행성·소행성·혜성의 분포 차이
- 근지구천체(NEO)와 지구위협천체(PHA)
- 2D/3D 궤도 구조와 역학적 분류 기준

핵심 질문은 단순히 “이 천체의 이름은 무엇인가?”가 아니라  
**“어떤 궤도 특성이 천체 유형을 구분하는 근거가 되는가?”**입니다.

## 🧭 추천 실습 순서

1. **데이터 전체 탐색** — 주요유형·세부유형의 개수와 기술통계 확인
2. **유형별 데이터 처리** — 행성·왜소행성·소행성·혜성 및 세부유형 비교
3. **분류 기준 찾기** — 장반경, 이심률, 경사각, Tj, MOID 관계 탐색
4. **개별 천체 분석** — 식별번호(pdes)를 입력해 2D/3D 궤도 생성
5. **분류 정답 확인** — 기존 분류와 자신이 찾은 기준 비교
6. **일반화** — 다른 천체에도 같은 기준이 적용되는지 설명
