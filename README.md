# Solar-System-Dynamical-Classification-Education

## 태양계 천체의 역학적 분류를 위한 데이터 사이언스 기반 천문 교육 콘텐츠

태양계 천체의 장반경, 이심률 등 궤도요소를 실제 카탈로그 데이터로 탐색·분석하고, 물리적 분류를 넘어 **역학적 분류 기준**을 이해하기 위한 Jupyter Notebook 기반 천문 교육 콘텐츠입니다.

### 관련 연구
**조훈 · 손정주, 「태양계 천체의 역학적 분류를 위한 데이터 사이언스 기반 천문 교육 콘텐츠 개발」**

## 주요 파일

- `태양계 천체 역학적 분류_분석 코드.ipynb` — 메인 Jupyter Notebook
- `dwarfplanet_asteroid_comet_analysis.csv` — 분석용 태양계 천체 데이터
- `solarsystem_analysis13.py` — 분석 함수
- `requirements.txt` — 실행 패키지 목록

## 실행 방법

1. 저장소를 ZIP으로 내려받거나 clone 합니다.
2. Python과 Jupyter Notebook 환경을 준비합니다.
3. `pip install -r requirements.txt`를 실행합니다.
4. `태양계 천체 역학적 분류_분석 코드.ipynb`를 엽니다.
5. 셀을 순서대로 실행합니다.

> GitHub에는 가독성과 용량 관리를 위해 Notebook 출력 결과를 제거한 버전을 올립니다. 코드 셀과 Markdown 내용은 유지합니다.
